# OMNI (web edition)

Open it: **https://szeszeming2-lgtm.github.io/omni/**

OMNI turns your phone, tablet or computer into one tool for the real world. It runs in the browser, with no account, API key or subscription.

- **Vision:** live QR codes and objects, text reading, photo analysis, visual search
- **Scanner:** find a page in a photo, flatten it, read it, export a PDF
- **Voice:** say "OMNI" while the page is open; timers, notes, sums, search and your own commands
- **Gesture:** hand tracking for palm, fist, pinch, point, victory, thumbs up and swipes
- **Spatial:** orientation, compass, level, shake and tilt events, a tilt game
- **Automation and Workshop:** When → If → Then routines, custom commands and control panels
- **Shortcuts:** run Apple Shortcuts, including Home scenes

**Privacy:** camera frames are analysed in your browser and never uploaded. Scans, notes and tools stay on your device. Voice uses your browser's speech recogniser, which may use the browser maker's service (Safari uses Apple's).

**What a website can't do:** control another computer, talk to HomeKit directly, use the flashlight in Safari, or run ARKit. Those features are in the native OMNI app.

The vision engines (MediaPipe, Tesseract) download from public CDNs the first time you use them.
